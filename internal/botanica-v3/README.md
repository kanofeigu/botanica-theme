# Botanica v3 — 文档集（给 DeepSeek / 实施者的入口）

本文件夹是 Botanica 主题**重做**的完整蓝图，用于通过 2026 Shopify Theme Store 审核。
前一版（Dawn 套壳）已被官方在设计初筛拒绝（根因：Dawn 派生主题自 2025-05-15 起一律不合格）。本套文档基于 2026-06 对官方规范的核实重写。

## 阅读顺序

| 文件 | 内容 | 给谁 |
|---|---|---|
| **00-AUDIT.md** | 为什么 v1 被拒；现有计划的错误/缺口逐条 + 修正 | 先读，理解背景 |

| **03-WORKFLOW.md** | 多-Agent 工作流（DAG 波次 + 三道审核门） | 编排器 |

## 怎么用（给实施者 DeepSeek）

1. 把 **02-PLAN.md** 当主蓝图，按 P0→P5 顺序施工，每阶段过门禁再前进。
2. 任何时候不得触犯 **02-PLAN.md §9** / **04-COMPLIANCE.md 红线**。
3. 实现 = 在 Skeleton 上**全原创代码** + **theme-blocks 架构**；禁用 Dawn/Horizon 任何代码。
4. 提交前用 **04-COMPLIANCE.md** 逐条勾完再提交。

## 三句话记住

1. **底座**：Skeleton + theme-blocks（规则强制，丢弃旧 Dawn 树）。
2. **定位**：多用途精品主题 + 植物旗舰 demo（避下架线、买家池大）。
3. **别赌**：只剩 2 次提交机会，按门禁一次做到位。
